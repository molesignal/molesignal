# Alibaba PuHuiTi 3.0 web subsets

These four self-hosted `.woff` files provide the product UI's existing font
weights:

- Regular (`400`)
- Medium (`500`)
- SemiBold (`600`)
- Bold (`700`)

The subsets contain all characters currently present in `web/src`,
`web/playwright`, `web/public`, and `web/index.html`, plus common Latin,
punctuation, currency, mathematical, arrow, symbol, and full-width Unicode
ranges.

Source fonts are Alibaba PuHuiTi 3.0 version 3.01:

- `AlibabaPuHuiTi-3-55-Regular`
- `AlibabaPuHuiTi-3-65-Medium`
- `AlibabaPuHuiTi-3-75-SemiBold`
- `AlibabaPuHuiTi-3-85-Bold`
