# Keyboard reference

> Generated by `pnpm -C web dump:keymap` from `web/src/keyboard/bindings.ts`.
> Do not edit by hand — CI verifies this is in sync with the source.

## General

| Keys | Action |
| ---- | ------ |
| `⌘+k` | Open command palette |
| `⌘+Esc` | Pop current scope / dismiss overlay |
| `⌘+/` | Show keyboard help |

## Investigation stack

| Keys | Action |
| ---- | ------ |
| `⌘+[` | Investigation stack: back |
| `⌘+]` | Investigation stack: forward |
| `⌘+⌥+y` | Copy investigation link |

## Navigation

| Keys | Action |
| ---- | ------ |
| `⌘+⌥+s` | Go to APM Services |
| `⌘+⌥+a` | Go to Alerts |
| `⌘+⌥+d` | Go to Dashboards |
| `⌘+⌥+t` | Go to Traces (Investigate) |
| `⌘+⌥+l` | Go to Logs (Investigate) |
| `⌘+⌥+r` | Go to APM User Experience |
| `⌘+⌥+f` | Go to Functions |
| `⌘+⌥+i` | Go to IAM |
| `⌘+down` | Move selection down |
| `⌘+up` | Move selection up |
| `⌘+Enter` | Activate focused row |

## Time

| Keys | Action |
| ---- | ------ |
| `⌘+⌥+e` | Open time window picker |
| `⌘+⌥+p` | Pin / unpin current cursor as anchor |
